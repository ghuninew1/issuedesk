# IssueDesk v1.4.0 — Release notes

รายการนี้สรุปการเปลี่ยนแปลงใน source ตั้งแต่ Git tag `1.3.4` ถึง checkout ปัจจุบัน การกำหนดเวอร์ชันใน repository ไม่ได้ยืนยันว่ามีการสร้าง tag, เผยแพร่ release หรือ deploy v1.4.0 แล้ว

## PDF Studio

- สมาชิกที่เข้าสู่ระบบสามารถรวม PDF จัดเรียง เลือก หมุน ลบ และแยกหน้า พร้อม undo/redo และ export ได้ใน browser
- Visual editor เพิ่มข้อความภาษา Latin ภาพ PNG/JPEG และ whiteout พร้อมย้าย ปรับขนาด ลบ และ undo/redo; whiteout เป็นการปิดทับภาพ ไม่ใช่การลบข้อมูลลับอย่างปลอดภัย และฟอนต์ที่ใช้เพิ่มข้อความยังไม่รองรับภาษาไทย
- บีบอัดแบบ Lossless สำหรับไฟล์ต้นฉบับเดียวที่ยังไม่แก้ไข โดยปฏิเสธเอกสารที่มีลายเซ็นหรือช่องลายเซ็น และอาจลดขนาดไม่ได้ ส่วนโหมดคุณภาพอื่นแปลงหน้าเป็นภาพและตั้งเป้าหมายขนาดแบบ best effort ได้ แต่อาจสูญเสียข้อความที่เลือกได้ ลิงก์ ฟอร์ม และข้อมูลโต้ตอบ
- PDF ประมวลผลใน browser ไม่ส่งเนื้อหาไปยัง API หรือเก็บถาวรใน browser storage

## Network Monitor

- เพิ่มข้อมูลอุณหภูมิ Router และ PPPoE IP/uptime เมื่อ agent และ RouterOS ส่งข้อมูลได้ พร้อม DHCP leases ล่าสุดสูงสุด 100 รายการและจำนวนทั้งหมด ตารางเรียง IP และเริ่มต้นย่ออยู่; lease ไม่ยืนยันว่าอุปกรณ์ออนไลน์
- การเก็บข้อมูลยังทำงานเมื่อมี viewer lease และ RouterOS อ่านแบบ read-only ฟิลด์ optional อาจไม่มีข้อมูลเมื่อ Router ไม่รองรับหรือปฏิเสธคำสั่ง
- D1 migration `0012_network_details.sql` เพิ่มข้อมูล PPPoE และ DHCP; `0013_network_lan_ports.sql` เก็บไว้ในลำดับ migration แม้ปัจจุบันแอปไม่ใช้ข้อมูล LAN bridge ports ตรวจสถานะและสำรองข้อมูลก่อนดำเนิน migration ที่ได้รับอนุญาต แยกจาก SQLite migration ของ Storage service

## Interface และการโหลดหน้า

- ปรับ Sidebar ให้รายการเมนูใช้ Liquid Glass hover เช่นเดียวกับปุ่ม Collapse และปรับพื้นที่เนื้อหาสำหรับ Sidebar บน desktop
- โหลด page modules แบบ lazy ภายใน shell ที่มี loading state ร่วม โดยหน้า login มี loading boundary ของตนเอง

## สถานะและข้อจำกัด

- การตั้งค่าและสถานะจริงของ Cloudflare Pages, D1, RouterOS agent และบริการภายนอกยังต้องตรวจใน environment เป้าหมาย การมี migration ใน repository ไม่ยืนยันว่า apply แล้ว
