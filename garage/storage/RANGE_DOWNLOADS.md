# Shared Storage v3 streaming Range downloads — Phase 5.1

2026-11-08. Source/local mocked validation only; not deployed or Garage-verified. No migration or feature flag activation. Upload/copy/v2 behavior and production settings remain unchanged.

`GET|HEAD /v3/projects/:projectId/objects/:objectId/download` retains app/project/logical ownership and deleted-tree checks. Garage HTTP download uses authoritative S3 HEAD, then conditional `GetObject(IfMatch, optional VersionId, optional Range)`. Checks response status/ETag/version/LastModified/ContentRange/exact length before exposing bytes, and counts streamed bytes to reject truncation/oversize. ETag is treated as an opaque provider validator, never as a content checksum. Public SHA-256 identity token hides provider metadata/references; caller sees no raw bucket/key/S3 tag.

Single closed/open/suffix ranges return206 and exact geometry; valid unsatisfiable range returns416 with `bytes */size`, length0. Malformed, unsupported units, multi-range and headers longer than256 characters fall back200. HEAD ignores Range, sends full metadata and never calls GET. If-Range supports matching opaque strong ETag; weak/stale/date values fall back200. Last-Modified dates cannot be established as strong (multiple modifications within a second), so they cannot authorize resume. A200 resume response must replace existing partial bytes. All private responses are no-store, nosniff and preserve safe filename/MIME policies.

`rangeRead` is explicit provider capability; Nexora must also check current read/download grants. Direct provider range/head requests use the checked HTTP adapter; ordinary legacy/v2 reads retain their former interface/deadline. Shared HTTP reads use existing provider timeout (default60s) as bounded connection/inactivity deadlines, reset on reads/chunks; no fixed total download timeout. Downstream stalls beyond idle deadline can abort. Cancellation aborts S3 and cancels/destroys body; no whole-file buffering. Separate controllers/counters per request permit concurrent downloads without shared mutable state. Provider must honor conditional snapshot semantics; that is an unverified real-Garage acceptance gate.

Tests use in-memory SQLite and mocked S3. `tests/range-download.test.js` covers metadata/races/geometry/length/cancel/deadlines; file-manager regressions exercise route semantics/auth/concurrency; disconnect tests use real loopback Hono Node responses for both legacy and Range streams. No runtime DB/WAL/SHM/config or real credentials are read. See Nexora `docs/LARGE_FILE_TRANSFER_DOWNLOAD.md` and `PROJECT_HANDOFF.md` for exact checks and real-provider/browser/Cloudflare acceptance requirements.
